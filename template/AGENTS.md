# 改动纪律

- 改全局插件（`system-prompt`、`permission-presets` 等）会导致所有会话重挂载，
  可能让正在跑的 GUI 会话断开。这类改动先说清影响，最好等用户空闲时做。
- 任何配置改动前先备份，改完立刻校验，并告知回滚路径。
